# MaletOS-Hyper-Files
MaletOS is an Operating System I made my self using Turbowarp. I started a few years ago and now have finally finished making the first version public for anyone who wants to try it.

Installation:
To install MaletOS, simply download the iso (i'm trying to make the iso be smaller, i swear, but right now it's like 14gb so you'll need a 16gb USB-Drive).
Then you can use a software like Rufus to flash the iso onto the USB.
About approximately 20 minutes it should be done and you can go try it out on your system.

Features:
MaletOS is a LIVE BOOT ONLY Operating System (at least for now), and does not have an installation.
MaletOS HAS internet functionality but only if you attach an Ethernet cord into your computer, WIFI does Not work.
The system it's self is trying to be nice looking, it does take inspiration from other OSs, but relatively tries to be it's own little thing.
It has a Calculator, Settings, Translator, Map, Paint, Flappy Bird, Notes app and 2 PDF files that explain a bit more when you're already in the OS (I recommend reading both the Tips and Welcome files on the desktop). It also has an Internet Folder with different Internet Applications.
Internet it very weird and most sites don't work.
